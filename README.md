# Sabujshop-
SabujShop হলো একটি ফ্রী, single-page ই-কমার্স সাইট যেখানে আপনি সহজে প্রোডাক্ট ব্রাউজ করতে, খুঁজে বের করতে এবং WhatsApp এর মাধ্যমে অর্ডার করতে পারবেন। এখানে প্রোডাক্ট লিস্টিং, ক্যাটেগরি ফিল্টার, সার্চ ফাংশন, Quick View পপআপ এবং কার্ট ফাংশনালিটি সবই এক পেজে উপলব্ধ। প্রতিটি প্রোডাক্টের শেয়ার লিঙ্ক ব্যবহার করে আপনি সহজেই Facebook, WhatsApp বা অন্যান্য।
